# Frontend Structure

- `index.html`: role-based route resolver
- `login.html`: authentication page
- `style.css`: shared styles for root pages
- `admin/index.html`: admin/hod dashboard
- `admin/style.css`: admin styles
- `student/index.html`: student shell layout (sidebar + iframe)
- `student/style.css`: student shell + student pages styles
- `student/pages/`: student feature pages (`dashboard-home`, `predict`, `placement`, `course-guide`, `notifications`, `rag-assistant`)
- `assets/js/auth/`: auth and route scripts
- `assets/js/admin/`: admin dashboard scripts
- `assets/js/student/`: student shell + page scripts
